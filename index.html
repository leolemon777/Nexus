说明
· S7 字节序为大端(与三菱 MC 相反),INT/REAL 按大端解码
· S7-1200/1500 的 DB 需为标准(非优化)块:TIA 中 DB 属性 → 取消勾选「优化的块访问」→ 重新编译下载
· S7-200 SMART 的 V 区自动映射 DB1:VB100 = DB1.DBB100、VW100 = DB1.DBW100、V100.3 = DB1.DBX100.3(支持 V 语法直接输入)
· 位写为读-改-写,不影响同字节其他位;STRING 类型前 2 字节为最大长度/实际长度头
· Web API(S7-1500 固件 ≥V2.8):连 HTTPS 443,用 JSON-RPC 符号寻址(可读优化块);选此变体后填 PLC 的 Web 用户名/密码(非 TIA 工程密码)
· Modbus TCP:S7-1200/1500 固件内置 Modbus server(默认 502),需 TIA 中启用 MB_SERVER 指令;直接切到 Modbus 主站页用网线连接即可
· 欧姆龙 FINS:TCP/UDP 端口 9600(不是串口波特率);接本体网口或 CJ1W-ETN21/CS1W-ETN21 模块
· 台达 DVP:老 ES/EX 编程口是 RS-232(Mini-DIN);ES2/EX2 才自带 COM2 RS-485;可扩 DVP-F485
· 汇川:H3U 编程口是 RS-422(Mini-DIN);H5U/AM 本体多为 RS-485;可扩 232/485 BD 模块
· S7-200 SMART:Port0 只有 RS-485,协议可选 PPI/Freeport/Modbus RTU/USS;CR20s-60s 无网口只能走 PPI
