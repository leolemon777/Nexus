# Nexus 2.0 UI 全面审查 — 问题清单与重构方案

## 当前布局的空间分配（1440×900）

```
窗口总高: 753px
├── Header:        52px  (7%)   ← 太高，logo+banner 可以合并
├── Sidebar:      230px  (18%宽) ← 太宽，只有一个协议项，大量空白
├── Module tabs:   46px  (6%)   ← 4个标签+session tab，可以精简
├── Connection:   131px  (17%)  ← 6字段+6按钮+6radio，密度过大
├── Workspace:    446px  (59%)  ← 主工作区
│   ├── Command:  203px  (46%)  ← 9字段+4按钮+指令列表，占太多
│   ├── Register: 128px  (29%)  ← 工具栏32px+tabs34px+表格31px+状态22px
│   └── Console:  100px  (22%)  ← tabs36px+内容62px，几乎看不到
└── Statusbar:     30px  (4%)
```

## 核心问题

### 1. 信息过载
- **58 个交互元素**同时显示（30 按钮 + 11 select + 9 input + 6 radio + 2 details）
- 用户视线需要在 5 个垂直堆叠的区域之间来回跳跃
- 没有任何"焦点区域"——所有东西都在抢注意力

### 2. 寄存器监控——核心功能区被挤压
- 表格可见高度仅 **31px**（一行数据都看不完整）
- 用户最常看的区域（当前值、实时数据）几乎不可见
- 需要滚动才能看到完整表格

### 3. 连接参数区——密度过高
- 6 个字段（串口/波特率/校验/数据位/停止位）+ 6 个按钮 + 6 个 transport radio
- 一行排不下时 wrap 到第二行，造成视觉混乱
- 高级参数藏在 details 里但入口按钮和其他按钮混排

### 4. 命令面板——次要参数占据黄金位置
- 倍率、单位、超时、轮询 这 4 个参数在大多数情况下用默认值
- 但它们占了一整行空间，把 FC/地址/数量 这些核心参数挤到边上
- 指令列表折叠面板又额外占了 30px

### 5. 侧边栏——空间浪费
- 230px 宽只显示一个 Modbus 协议项 + 装饰性图案
- 可以缩到 48px（仅图标）或 64px（图标+文字缩写）

### 6. 头部——信息密度低
- 64px 高的 header 只显示 logo + 模块名 + 连接状态
- workspace-title 和 connection-state 可以合并到一行

### 7. Console 面板——永远不够高
- 100px 高度中，tabs 占 36px，实际内容只有 62px
- 只能显示 2 行报文，用户需要频繁滚动

## 重构方案

### 方案：三栏 + 聚焦布局

**设计原则**：
1. **寄存器监控是主角**——给它最大的可见空间
2. **次要参数收起来**——倍率/单位/超时/轮询放入弹出面板
3. **连接参数可折叠**——连接后只需一行摘要
4. **Console 默认收起**——点击展开看详情
5. **侧边栏极简化**——仅图标，48px

### 目标空间分配（1440×900）

```
窗口总高: 753px
├── Header:        40px  (5%)   ← 精简，logo+标题+状态一行
├── Sidebar:        48px  (4%宽) ← 仅图标
├── Module tabs:    36px  (5%)   ← 精简
├── Connection:     42px  (6%)   ← 折叠态：摘要行 + 展开按钮
│   (展开时):      120px         ← 展开态：完整表单
├── Workspace:    550px  (73%)  ← 大幅增加
│   ├── Command:   90px  (16%)  ← 精简：核心参数+操作按钮
│   │   (详情):    +60px         ← 可选展开：倍率/单位/超时/轮询
│   ├── Register: 320px  (58%)  ← 主角：表格+工具栏+状态栏
│   └── Console:   42px  (8%)   ← 收起态：tabs 摘要
│       (展开):   180px         ← 展开态：完整报文表格
└── Statusbar:      28px  (4%)
```

**效果对比**：
- 寄存器表格可见高度：31px → **~260px**（8倍提升）
- 一屏可见交互元素：58 → **~35**（减少 40%）
- 用户首次打开的关注点：寄存器监控（而非连接参数）
