# 协议通讯设置帮助窗规格（v1.0）

> 日期：2026-08-22  
> 状态：用户已明确要求实现  
> 范围：仅新增本地说明型 UI，不修改协议帧、连接逻辑、PLC 参数、网卡或串口配置。

## 1. 目标

在每个通讯页面的连接配置区增加“通讯设置帮助”按钮。点击后打开统一小窗口，并按照当前选中的协议变体显示：

1. 连接介质：网线、RS-232、RS-422、RS-485 或网关；
2. 必填参数：IP、端口、COM、波特率、数据位、校验、停止位、站号、Rack/Slot、FINS 节点等；
3. 设备侧如何设置；
4. 电脑/Nexus 侧如何设置；
5. 连接前检查、常见错误和安全边界；
6. 当前页面已经填写的参数快照。

## 2. 覆盖范围

| 页面 | 帮助覆盖的变体 |
|---|---|
| Modbus 主站 | RTU、ASCII、TCP、UDP、RTU over TCP、ASCII over TCP |
| Modbus 从站 | TCP 监听、RTU 串口监听 |
| 串口调试 | 通用 RS-232/RS-422/RS-485 串口参数 |
| 三菱 | 3E、4E、ASCII 3E/4E、UDP 3E/4E、A-1E、MC-C24、FX Computer Link、FX 编程口 |
| 西门子 | S7comm、S7-200 SMART、PPI 网关、Fetch/Write、USS、3964R/RK512、Web API |
| 欧姆龙 | FINS/TCP、FINS/UDP |

报文解析是离线工具，本轮不增加 IP/串口配置帮助。本机接口页已经提供网卡、COM 和 USB 识别，也不重复增加协议帮助。

## 3. 交互

- 每个连接配置卡右上角显示同名按钮。
- 打开时默认选中当前页面正在使用的协议变体。
- 弹窗内可以只切换帮助条目，不改变主页面的真实连接选择或参数。
- 支持关闭按钮、Esc 和点击遮罩关闭。
- 小窗口适配窄屏并支持滚动；不遮挡后仍可恢复原页面焦点。
- 所有内容随应用离线打包，不访问外网。

## 4. 内容纪律

- “常用值”只作为起步示例，必须明确最终以 CPU/模块/仪表说明书和工程配置为准。
- 网络层 Ping/TCP 可达不能替代协议响应。
- PLC 首次实机连接默认只读；不引导用户写输出、强制线圈或远程启停。
- 三菱 FX3U-ENET-ADP 演示主线标明 A-1E；S7-200 SMART V3 标明 Put/Get Server 前置条件。
- 对尚未接入专用在线流程的变体，帮助窗必须明确标注“参数准备说明”，不得伪装为已完成真机连接入口。

## 5. 实现结构

- `src/protocol-guides.js`：唯一内容表和纯函数查询接口。
- `index.html`：六个入口按钮和一个共享 `<dialog>`。
- `src/main.js`：读取当前页面参数、渲染、切换、关闭和焦点恢复。
- `src/app.css`：帮助窗、参数表、步骤卡和响应式布局。
- `electron/protocol-guide-ui.test.cjs`：覆盖条目、HTML 接线和关键交互静态检查。

## 6. 验收

1. 六个页面均能打开帮助窗；
2. 当前变体自动对应正确条目；
3. 弹窗切换条目不修改主页面任何字段；
4. 网络协议显示 IP/端口，同步显示设备侧和电脑侧步骤；
5. 串口协议显示 COM、波特率、数据位、校验、停止位和站号说明；
6. `npm run test:electron`、`npm run build` 和 Electron smoke 通过；
7. 新便携版打包后完成 portable smoke。
